# ml-course-figures

Власні рисунки до курсу «Машинне навчання» (магістратура, 14 лекцій).

Побудовані скриптами `lecNN_figs.py` через єдиний візуальний модуль
`mlviz.py` на відкритих наборах даних: Breast Cancer Wisconsin, Iris,
Wine, Digits, California Housing, MNIST, Titanic.

Тут лежать **тільки авторські рисунки** — ті, для яких не знайшлося
готового відповідника в документації scikit-learn, d2l.ai, CS231n
чи Wikimedia Commons. Канонічні схеми беруться з першоджерел із
посиланням на них просто в презентації.

Репозиторій публічний з однієї технічної причини: Gamma завантажує
зображення за прямим URL під час генерації презентації.
